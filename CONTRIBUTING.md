# Contributing to Christopher Ross Plugins

If you've used one of these plugins and want to help make it better, this is the place to start. Code, bug reports, edge-case testing — all useful.

## Code of Conduct

Be respectful. Assume good intent. We're working on the same problem from different angles.

## How to Contribute

### Reporting Issues

Found a bug or have an idea?

1. Check existing issues first to avoid duplicates.
2. Open a new issue with a clear title and description.
3. For bugs, include reproduction steps.
4. Include your WordPress and PHP version.

### Submitting Code

PRs are welcome. The flow:

1. Fork the repository.
2. Create a branch for your change: `git checkout -b feature/your-feature-name`
3. Make your changes, keeping commits atomic and well-described.
4. Follow [WordPress Coding Standards](https://developer.wordpress.org/coding-standards/).
5. Test your code thoroughly.
6. Push to your fork and open a pull request.
7. Describe what you changed and why.

### Code Standards

- Follow WordPress Coding Standards.
- Use 1 tab indentation for PHP.
- Include docblocks for functions.
- Test on the minimum supported WordPress and PHP versions.

### What Gets Reviewed

- Does it solve the stated problem?
- Is it compatible with supported WordPress/PHP versions?
- Does it follow WordPress Coding Standards?
- Are there any security concerns?
- Does it include tests or documentation?

### Review Timeline

I aim to review within 1-2 weeks. Sometimes it's faster, sometimes slower depending on what else is on. Thanks for your patience.

## Questions?

Open a discussion or an issue. Any question is fair game.
